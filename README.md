## Build and maintain

```bash
python build.py
python validate_site.py
```

Python’s standard library generates static HTML. CSS provides the responsive layout. The small JavaScript file handles section navigation, links into collapsed content, progress and legacy bookmarks. Native `details`/`summary` controls keep the record usable without JavaScript.

`data/modules.json` retains the full module records and activity scores. `data/awards.json` stores official references, with images in `assets/awards/`. `data/takeaways.json` stores the five themes. Public evidence comprises four reviewed CSV extracts and one screened notebook. Original submissions and workbooks remain private; Git history preserves earlier presentations.

GitHub Pages serves the repository root from `main`. No private learner identifiers, credentials, session URLs or patient records are published.
