## Build and maintain

```bash
python build.py
python validate_site.py
```

The site uses Python’s standard library to generate static HTML, CSS and a small compatibility script. `data/modules.json` retains all 24 module records and activity scores. `data/awards.json` retains the official references; images are in `assets/awards/`. Five takeaway themes are stored in `data/takeaways.json`.

The public evidence files comprise four reviewed CSV extracts and one screened notebook. Original submissions and workbooks remain private. Git history preserves the earlier, more detailed presentation.

GitHub Pages serves the repository root from `main`. No private learner identifiers, credentials, session URLs or patient records are published.
