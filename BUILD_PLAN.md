# Portfolio development plan

## Purpose

Present Ian Alleyne’s completed 24-module MIT xPRO course as a professional, evidence-based record of analytics, optimization, responsible AI and transformation leadership. Make the final 100% achievement prominent without treating a grade as proof of deployment success.

## Information architecture

| Page | Purpose |
| --- | --- |
| Home | Professional introduction, verified achievement, selected work and searchable module catalogue |
| 24 module pages | Concepts, personal work, decision-making insight, potential application, artifacts and final activity grades |
| Four case studies | Clinical AI, alarm intelligence, production optimization and network logistics |
| Achievement | All module totals, total points, grade interpretation and public credential |
| Credentials & recognition | Official completion-certificate image, two exemplary-assignment badges, issue dates and verification links |
| Evidence & authorship | Source provenance, assistance, export limitations and corrections |
| Portfolio plan | Reader-facing explanation of this structure and future work |

## Course guidance applied

The course’s Developing Your Portfolio page recommends GitHub, transferable Google Colab notebooks and noncoding interpretation assignments. Codio notebooks are not available for export; summarize their learning and results rather than inventing replacement submissions. Avoid rehosting lecture transcripts, quizzes, datasets or classmates’ work.

## Build sequence

1. Verify the authenticated completion and grade records; reconcile all 24 modules and 144 activities to 813/813.
2. Inventory submitted files and text responses. Recover work privately, prepare reviewed numerical extracts and document unavailable hosted code.
3. Write original summaries and four deeper cases. Distinguish course results from proposed operational applications.
4. Build a responsive static site with keyboard-accessible navigation, searchable modules and evidence links.
5. Check links, numerical claims, privacy boundaries, mobile layout and search behavior.
6. Publish to GitHub Pages and connect the GitHub profile to the portfolio.

## Design

Navy, cream and teal with a restrained gold achievement accent. Editorial serif headlines paired with readable system sans-serif text. No tracking, external fonts or client-side frameworks. All module pages work without JavaScript; filtering is progressive enhancement.

## Maintenance and future work

- Add personally owned Colab exports after checking access, attribution and reproducibility.
- Create independent reproductions of selected Codio exercises and label them as later work.
- Add publicly shareable measured pilot results when available, with baselines and limitations.
- Maintain corrections in git history. Keep original submitted artifacts separate from later revisions.
- For every new project: decision, data, method, supported result, limitations, evidence and deployment considerations.
